The text column carries `basis-72` on purpose. A bare `flex-1` is `flex: 1 1 0%`, so the row's `flex-wrap` never fires — the browser sees a zero-width item that always "fits", keeps the actions on the same line, and crushes the name and description into a one-word-per-line column. An 18rem basis makes the row wrap the actions onto their own line before that can happen. {% endcomment %}
